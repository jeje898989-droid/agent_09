# PPT 규칙 (v1)

이 프로젝트에서 발표자료(.pptx)를 만들거나 고칠 때마다 이 규칙을 적용한다.
`mk-ppt` 스킬과 함께 사용한다.

## 1. 슬라이드 수

- 기본적으로 표지 슬라이드를 포함해 **8장**을 만든다.
- 사용자가 따로 요청할 때만 다른 장수를 쓴다.
- 내용이 8장에 다 들어가지 않으면, 슬라이드를 늘리기 전에 사용자에게 알리고 물어본다.

## 2. 디자인 참고

- 발표자료를 만들기 전에 사용자가 제공한 디자인 `.md` 파일을 읽고, 그 파일의 색상, 글꼴, 레이아웃, 스타일을 따른다.
- 사용자가 디자인 파일을 주지 않았다면 시작하기 전에 요청한다. 사용자가 파일 없이 진행하라고 하면 `mk-ppt` 스킬의 기본 테마를 쓴다.
- 디자인 파일이 `mk-ppt` 스킬의 기본 테마와 충돌하면 디자인 파일을 따른다.
- 최종 보고에서 따른 디자인 파일의 이름을 밝힌다.

## 3. 가독성: 넘침 금지, 겹침 금지

- **텍스트를 슬라이드 안에 둔다.** 모든 텍스트 상자와 도형은 슬라이드 영역 안에 완전히 들어가야 하며, 각 가장자리에서 안전 여백(최소 0.4 in / 1 cm)을 둔다.
- **슬라이드당 텍스트 양을 제한한다.** 제목은 한 줄, 불릿은 한 줄짜리 3–6개로 한다. 긴 설명은 발표자 노트로 옮기거나 여러 슬라이드로 나눈다. 텍스트를 맞추려고 글꼴을 14pt보다 작게 줄이지 않는다.
- **요소끼리 겹치지 않게 한다.** 텍스트 상자, 도형, 이미지, 표, 차트의 위치와 크기를 계산해서 서로 가리지 않게 배치한다. 단, 의도한 겹침(예: 배경 도형 위의 텍스트)이고 텍스트가 잘 읽히면 괜찮다.
- **만든 뒤에 검사한다.** `python .claude/skills/mk-ppt/scripts/pptx_kit.py inspect <deck>`를 실행해 `!! OFF-SLIDE` 표시가 붙은 도형이 없는지 확인한다. `inspect`는 텍스트와 안전 여백을 측정하지 않으므로, 상자 밖으로 넘친 텍스트가 없고 도형이 여백을 지키는지 따로 확인한다. 문제를 모두 고치고 다시 만든 다음에 완료를 보고한다.
