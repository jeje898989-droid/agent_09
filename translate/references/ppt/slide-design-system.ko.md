# 슬라이드 디자인 시스템

"Project Management Infographics" 템플릿(4열 SWOT 카드 레이아웃)을 바탕으로 한 슬라이드 디자인
참고 문서입니다. `mk-ppt` 스킬, `ppt-rule-v1`과 함께 사용합니다.

## 1. 분위기

깔끔하고 밝으며 친근한 느낌입니다. 흰 배경, 굵은 장체(condensed) 제목, 항목마다 따뜻한 색에서
차가운 색으로 이어지는 선명한 색 하나를 씁니다. 얇은 검은 외곽선과 단순한 선 아이콘으로 가볍고
읽기 쉽게 유지합니다.

## 2. 캔버스

- 16:9, 13.333 × 7.5 in, 흰 배경(`#FFFFFF`).
- 좌우 여백은 약 1.0 in. 모든 요소는 가장자리에서 최소 0.4 in 안쪽에 둡니다.

## 3. 색상

| 역할 | HEX | 용도 |
|---|---|---|
| 강조색 1 – 노랑 | `#FBB92F` | 1번째 항목 헤더, 아이콘, 소제목 |
| 강조색 2 – 코랄 | `#FB8567` | 2번째 항목 |
| 강조색 3 – 핑크 | `#FB569B` | 3번째 항목 |
| 강조색 4 – 보라 | `#9C28B1` | 4번째 항목 |
| 텍스트 | `#000000` | 제목, 본문, 카드 외곽선 |
| 배경 | `#FFFFFF` | 슬라이드, 카드 채우기, 헤더 라벨 글자 |

- 강조색은 순서대로(노랑 → 코랄 → 핑크 → 보라) 배정해 흐름이 그라데이션처럼 읽히게 합니다.
- 한 항목은 헤더 채우기, 아이콘, 소제목 모두 같은 강조색 하나만 씁니다.
- 검정은 텍스트와 외곽선에만 쓰고, 회색 채우기나 그라데이션은 쓰지 않습니다.

## 4. 폰트

| 요소 | 폰트 | 크기 | 스타일 |
|---|---|---|---|
| 슬라이드 제목 | Fira Sans Extra Condensed (한글: Noto Sans KR) | 36–40pt | 굵게, 검정, 가운데 정렬 |
| 헤더 라벨 | Fira Sans Extra Condensed (한글: Noto Sans KR) | 22–24pt | 굵게, 흰색, 영문은 대문자 |
| 카드 소제목 | Fira Sans Extra Condensed (한글: Noto Sans KR) | 22–24pt | 굵게, 강조색 |
| 본문 | Roboto (한글: Noto Sans KR) | 16–18pt | 보통, 검정, 가운데 정렬 |

- 한글 슬라이드는 동아시아 글꼴을 Noto Sans KR로 지정하고, 14pt 아래로 줄이지 않습니다.

## 5. 레이아웃: 카드 열 (대표 레이아웃)

```
          [ 슬라이드 제목, 가운데 ]
 ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
 │  헤더  │ │  헤더  │ │  헤더  │ │  헤더  │  ← 강조색 채우기, 위쪽 둥근 모서리
 └────────┘ └────────┘ └────────┘ └────────┘
 ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
 │ 아이콘 │ │ 아이콘 │ │ 아이콘 │ │ 아이콘 │  ← 흰 카드, 검은 외곽선
 │ 소제목 │ │ 소제목 │ │ 소제목 │ │ 소제목 │
 │  본문  │ │  본문  │ │  본문  │ │  본문  │
 └────────┘ └────────┘ └────────┘ └────────┘
```

| 요소 | 왼쪽 / 위 (in) | 크기 (in) |
|---|---|---|
| 제목 | 가운데 / 0.7 | 전체 너비 × 0.8 |
| 헤더 바 | 1.03 + n × 2.89 / 1.9 | 2.62 × 0.85 |
| 카드 | 같은 x / 2.93 | 2.62 × 3.52 |

- 4열, 간격 0.27 in. 헤더는 카드 위 0.18 in 지점에 놓습니다.
- 헤더 바: 강조색 채우기, 외곽선 없음, 위쪽 모서리만 둥글게.
- 카드: 흰 채우기, 1.5pt 검은 외곽선, 작은 모서리 반경(약 0.1 in).
- 카드 안은 위에서 아래로 아이콘(약 0.7 in) → 소제목 → 본문 2–3줄, 모두 가운데 정렬.
- 항목이 2–3개면 카드 크기는 그대로 두고 묶음 전체를 가운데에 둡니다.

## 6. 기타 슬라이드

- **표지:** 큰 가운데 제목, 강조색 하나로 쓴 부제, 장식으로 작은 강조색 막대나 점 4개를 한 줄로.
- **글머리표 슬라이드:** 위에 제목, 검은 외곽선의 흰 카드 하나에 글머리표 3–6개,
  카드 왼쪽에 얇은 강조색 막대(한 가지 색).
- **표 / 차트:** 머리글 행이나 계열 색은 강조색 순서를 따르고, 글자는 검정, 선은 얇게.
- **마무리 슬라이드:** 표지와 같은 스타일.

## 7. 아이콘과 그래픽

- 단순한 선 아이콘(외곽선만, 선 두께 약 2pt)을 항목의 강조색으로.
- 사진, 그림자, 3D 효과, 그라데이션은 쓰지 않습니다.

## 8. 해야 할 것 / 하지 말 것

- **할 것:** 여백을 넉넉히, 카드 내용은 가운데 정렬, 항목마다 강조색 하나.
- **하지 말 것:** 한 카드에 여러 강조색 섞기, 카드를 색으로 채우기, 그림자 넣기,
  카드 본문을 3줄 넘게 쓰기.
